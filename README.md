# AI Voice Agentic

Research notes and reference implementations exploring agentic AI voice systems — real-time conversational agents, speech pipelines, and telephony integration patterns.

## Contents

- [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) — high-level architecture notes for a typical agentic voice pipeline (STT → LLM → TTS, orchestrated over a real-time transport layer)
- [`examples/voice_agent_demo.py`](examples/voice_agent_demo.py) — a minimal, illustrative example of a conversational turn-taking loop for a voice agent

## Focus areas

- Real-time speech-to-text and text-to-speech pipelines
- Turn-taking, interruption handling, and latency optimization
- LLM-driven conversational agents for voice
- Telephony integration (SIP, WebRTC) for voice agents

This is a working notes repository — expect ongoing updates as research continues.
